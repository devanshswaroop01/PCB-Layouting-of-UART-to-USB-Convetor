
USB-to-UART Converter PCB
Drill Files Report
PCB Hole Fabrication Documentation

Project Title: USB-to-UART Converter PCB

Software Used: KiCad PCB Editor 9.0.7

Report Scope: PCB Drill Files Only

1. Introduction

This report documents the drill files generated for the USB-to-UART Converter PCB. Drill files define the locations, diameters, and types of holes required during PCB fabrication. These files are used by CNC drilling machines to produce plated and non-plated holes before the board proceeds to subsequent manufacturing stages.

The report is limited to the drill output generated from the completed PCB layout.

2. Drill File Generation

The drill data was generated using KiCad PCB Editor.

Parameter	Description
Software	KiCad PCB Editor
Version	9.0.7
Output Format	Excellon Drill Format
Units	Millimeter
Coordinate Type	Absolute Coordinates

The generated drill files contain all drilling information required for fabrication.

3. Generated Drill Files

The following drill files were produced.

File	Description
USB_to_UART-PTH.drl	Plated Through Hole Drill File
USB_to_UART-NPTH.drl	Non-Plated Through Hole Drill File
4. Plated Through Hole (PTH) Drill File
File
USB_to_UART-PTH.drl
Purpose

The plated drill file contains all holes that are electrically connected to the PCB circuitry. During fabrication, these holes are metallized to establish electrical continuity between the top and bottom copper layers.

Typical Applications
Signal vias
Power vias
Through-hole component leads
Pin headers
Connectors
5. Drill Tools Used (PTH)

The plated drill file defines three drill tool sizes.

Tool	Drill Diameter	Typical Application
T1	0.30 mm	Signal vias
T2	0.60 mm	Through-hole component leads
T3	1.00 mm	Pin headers and connectors
Design Considerations
Small drill diameter used for compact signal vias.
Medium drill diameter used for standard through-hole components.
Larger drill diameter allocated for connector and header pins.
6. Non-Plated Through Hole (NPTH) Drill File
File
USB_to_UART-NPTH.drl
Purpose

The NPTH drill file contains holes that are not electrically connected to the PCB. These holes remain unplated and are intended solely for mechanical purposes.

Typical Applications
Mechanical alignment holes
Connector locating pins
Mounting features
Mechanical supports
7. Drill Tools Used (NPTH)

The non-plated drill file defines one drill size.

Tool	Drill Diameter	Typical Application
T1	0.65 mm	Mechanical locating holes

The generated file contains the required non-plated holes for the PCB design.

8. Classification of PCB Holes

PCB holes are categorized according to their intended function.

Hole Type	Electrical Connection	Plating
Signal Via	Yes	Plated
Component Lead	Yes	Plated
Connector Pin	Yes	Plated
Mechanical Hole	No	Non-Plated
